# Other trackers

Map each state to the tracker's own field, in this order of preference:

1. A workflow status the team already has (Linear "Triage" and "Backlog", Jira "Needs info").
2. A label with the state name.

Use the tracker's MCP server or CLI if one is installed. If none is, list the commands you would
run and ask the person to run them.

The comment, the disclaimer line and the brief stay the same on every tracker.
