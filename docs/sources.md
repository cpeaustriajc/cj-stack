# Sources

The stack audit (root `CLAUDE.md`) starts when one of these sources publishes a best-practice
article on coding agents, or when a frontier model ships from a vendor the stack runs on. Read
the new article, then trim the stack before you add to it.

## Trust levels

- **Primary**: the people who did the work wrote it: a vendor's engineers on their own product
  or study, or a practitioner on their own repo. Cite it.
- **Secondary**: someone reports or analyses a primary source (a news article, a review of a
  study, a talk about another team's work). Cite it only with the primary source it rests on, or
  mark the claim UNVERIFIED.
- **Tertiary**: a summary of summaries: an aggregator list, a newsletter roundup, a generated
  overview, a wiki page. Never cite it. Use it only to find the primary source.

The level belongs to the article, not the site: a vendor blog post that reports another team's
study is secondary.
